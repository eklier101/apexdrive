# Privacy Policy — ApexDrive

**Last updated:** 2026-09-07

ApexDrive is a self-hosted vehicle expense and maintenance tracker. The Android and web clients connect to **a server you (or your administrator) operate**. There is no ApexDrive cloud account that collects your vehicle data by default.

## What the app stores

- **On your server:** vehicle logs, fuel/service/expense records, account credentials (password hashes), and optional uploaded receipts you choose to store.
- **On your device:** login session token, cached vehicle summaries, and the server URL you configure.
- **Play Store build:** app updates are delivered by Google Play. This build does **not** download or install APKs from your server.
- **Sideload / GitHub APK:** may download update packages from **your** ApexDrive server when you enable that feature.

## What we (the project authors) do not collect

The open-source project does not run a mandatory analytics backend. We do not receive your fill-ups, VINs, or passwords when you self-host.

If you use Google Play, Google may process install and crash data under [Google Play’s policies](https://policies.google.com/privacy).

## Permissions (Android)

Depending on build:

- **Internet / network state** — talk to your ApexDrive server.
- **Notifications / alarms** — optional maintenance reminders.
- **Install packages (sideload build only)** — install APK updates from your server.

## Contact

For privacy questions about this open-source project, open an issue on the [ApexDrive GitHub repository](https://github.com/eklier101/apexdrive/issues).

If you operate a public instance for others, you are the data controller for that instance and should publish your own policy covering your hosting practices.
